# 封包前检查清单

## 当前状态

当前项目已经进入“可封包前准备阶段”：

- 桌面端主流程已具备
- 初始化私有仓库已改为最小运行集同步
- 设置页 / 上传页已完成主要产品化整理
- Tauri 图标资源已生成
- 打包配置已接入基础图标和窗口参数

## 封包前需要再确认

### 1. 产品体验

- 首次启动路径是否足够清晰
- 设置页的仓库配置、语言设置、开发者账号配置是否易懂
- 上传页在“无账号 / 无 IPA / 未配置仓库”时是否足够明确
- toast 提示是否符合预期

### 2. 功能自测

- 能保存仓库设置
- 能检查 GitHub 连接
- 能初始化私有仓库
- 能添加、编辑、删除开发者账号
- 能选择 IPA 并发起上传
- 能打开 GitHub Actions 页面

### 3. 异常场景

- token 为空
- repo 填写错误
- profile 信息不完整
- IPA 未选择
- GitHub API 返回错误
- 初始化仓库失败

### 4. 打包资源

- `desktop/src-tauri/icons/` 已包含基础打包图标
- `desktop/src-tauri/tauri.conf.json` 已配置窗口大小、最小尺寸、图标
- macOS 目标：`dmg`
- Windows 目标：`nsis`

## 封包时执行

在确认无误后，再执行：

```bash
cd desktop
npm run tauri:build
```

## 当前建议

封包前建议再做一轮真实上传链路回归测试，然后再正式出包。
